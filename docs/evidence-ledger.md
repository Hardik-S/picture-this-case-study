# Picture This! Evidence Ledger

This ledger keeps the public case study honest by separating what the repo can prove today from claims that must wait for sanitized supporting artifacts.

| Sanitized artifact | Evidence status | Public-use decision |
| --- | --- | --- |
| Static prototype page | Committed in `index.html` with synthetic screens. | Safe to show as a concept artifact. |
| Product rationale | Documented in `docs/case-study.md`. | Safe to cite as decision rationale. |
| Review signals | Named without raw participant data. | Safe as a validation plan, not traction proof. |
| Usability notes | Not yet added. | Do not claim traction from private notes. |
| Pitch or investor material | Not included. | Do not publish without explicit review. |

## Decision Notes

The ledger exists so future resume copy can point to specific artifacts rather than broad product claims. It also documents a rejected shortcut: publishing raw pitch-deck snippets would make the project look more complete, but it would mix private context into a public recruiter surface.

## Next Evidence To Add

Add anonymized usability notes only after names, course context, private feedback, and unsupported traction claims are removed. Keep each new claim tied to a file path in this repo so reviewers can inspect the evidence directly.
